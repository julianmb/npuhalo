# Research Notes

This directory intentionally contains only curated public research notes.

The original working material was an AI-assisted conversation export containing
duplicate claims, opaque redirect links, machine-specific details, and
contradictory IOMMU guidance. It was removed before publication rather than
presented as verified documentation.

Use these reviewed documents instead:

- [`../final_verdict.md`](../final_verdict.md): speculative-decoding decision and corrected assumptions.
- [`../REPORT.md`](../REPORT.md): measured NPU/iGPU experiments and historical prototypes.
- [`../../verifier/results/final-report.md`](../../verifier/results/final-report.md): live-verification evaluation, limitations, and reproduction status.
- [`../../standalone-eval/results/`](../../standalone-eval/results/): standalone verifier characterization.

Claims in this repository should be treated as measured only when the relevant
report labels them as measured and identifies the workload. Historical designs
and modeled projections are not production recommendations.
